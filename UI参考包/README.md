# 云间小窝 UI 参考包

本目录把用户提供的界面拼图整理成单屏参考，并附上可编辑 SVG 重绘稿，便于后续在微信小程序中按图还原。

## 目录说明

- `界面原图裁切/`：从原始拼图逐屏裁切的截图，按 3 倍尺寸放大以便查看。原图每个屏幕宽度约 196–250 像素，放大不会凭空增加细节；原图截图是视觉样式和插画的首要参考。
- `SVG可编辑参考/`：按 390×844 画布重新绘制的 SVG。文字、色块、卡片和图形均可编辑；它们是结构与布局参考稿，不是原始图片的矢量源文件，插画和部分图标为简化示意。
- `给Codex的还原提示词.md`：可以直接复制到 Codex 的实现提示词。

## 视觉基准

- 页面底色：奶白、暖灰、浅燕麦色；卡片使用暖白，圆角约 16–24px。
- 主要文字使用灰蓝色；强调色为低饱和雾蓝；插画可点缀浅杏、奶油黄和灰绿。
- 留白充足，标题和正文层级清楚；阴影很浅，避免厚重描边和高饱和色块。
- 组件包括状态栏、顶部导航、内容卡片、圆角胶囊按钮、三栏底部导航。
- 星图使用深蓝夜空、柔和星点和城市名；其他页面整体维持安静的暖白主题。
- 动画如需实现，只使用缓慢淡入、轻微漂浮和星点呼吸，不添加弹跳、点赞、热度或排行榜。

## 产品文案与伦理边界

应用是思念记录与 AI 陪伴空间，不代表宠物复活，也不能与宠物真实沟通。所有页面文案克制温和；社交内容默认匿名；位置信息可选，不请求精确 GPS。不要新增点赞、收藏、私聊、关注、评论楼层、排行或引流玩法。独处安静模式应关闭所有社交模块，仅保留档案和悄悄话信箱。
